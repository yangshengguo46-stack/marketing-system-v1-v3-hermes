# Viral Title Writer

## When to Use
- Writing titles for short videos
- Creating headlines for articles/posts
- A/B testing title variants
- Optimizing click-through rates

## Title Formula Library

### Curiosity Gap
```
"X%的人不知道的Y"
"关于X，你不知道的Y件事"
"终于有人把X说清楚了"
"X的真相，和你想的完全不一样"
```

### Number + Benefit
```
"X个Y技巧，第Z个最关键"
"X天Y，我是怎么做到的"
"X个Y误区，你中了几个"
"只用X，就能Y"
```

### Contrarian
```
"别再X了，Y才是对的"
"X没用！Y才是真相"
"你以为X很难？其实Y就够了"
"X都是骗人的，Y才是真的"
```

### Story + Transformation
```
"从X到Y，我只用了Z天"
"X年Y经验，总结出Z条铁律"
"我是怎么从X变成Y的"
"放弃X之后，我Y了"
```

### Authority + Specificity
```
"做了X年Y，我总结出Z"
"X位Y专家的共识：Z"
"X行业内部人才知道的Y"
"X年Y经验，一句话总结"
```

### Urgency + FOMO
```
"不看后悔！X之前赶紧Y"
"X之前，你还有Z次机会"
"再不X就晚了"
"限免！X仅剩Y个名额"
```

## Emotional Trigger Words

### 高点击率词汇
| 类别 | 词汇 | 效果 |
|------|------|------|
| 数字 | 3个、90%、7天、100% | 具体感、可信度 |
| 极端词 | 终于、竟然、万万没想到 | 意外感、好奇心 |
| 痛点词 | 别再、亏了、后悔、踩坑 | 损失厌恶 |
| 收益词 | 搞定、涨粉、变现、省时 | 利益驱动 |
| 权威词 | 内部、真相、揭秘、底层 | 信息差渴望 |
| 时间词 | 2025最新、现在、趁早 | 紧迫感 |
| 限定词 | 只有、仅剩、最后一个 | 稀缺性 |

### 避免词汇
| 词汇 | 原因 |
|------|------|
| 震惊 | 平台限流标记 |
| 速看 | 平台限流标记 |
| 绝密 | 夸张标记 |
| 点击 | 诱导点击标记 |
| 99%的人 | 过度使用，效果下降 |

## Title A/B Testing Framework

### Generate 3 Variants

```markdown
## A/B/C Title Test

**Variant A** (Curiosity Gap):
"关于短视频算法，你不知道的3个真相"

**Variant B** (Contrarian):
"别再研究算法了，内容才是王道"

**Variant C** (Authority):
"做了5年短视频，我总结出3条算法铁律"

**Prediction**: [Which will perform best and why]
**Test metric**: Click-through rate (CTR) at 1 hour
**Winner criteria**: >20% lead over second place
```

### Testing Rules
- Test ONE variable at a time (same content, different title)
- Minimum sample: 1000 impressions before calling
- Test at same time of day
- Consider position bias (first seen = advantage)

## Title + Cover Synergy

The title and cover must work together:

### Pattern 1: Title completes cover
- Cover: "3个技巧" (big text)
- Title: "涨粉最快的3个技巧，最后一个绝了"
- Effect: Cover creates curiosity, title delivers promise

### Pattern 2: Title contradicts cover
- Cover: Sad face + "失败"
- Title: "我是如何从失败中找到成功之路的"
- Effect: Tension between image and text = curiosity

### Pattern 3: Title explains cover
- Cover: Before/after comparison image
- Title: "30天从X到Y，方法其实很简单"
- Effect: Image proves, title contextualizes

## Series Title Patterns

### Numbered Series
```
"新手做自媒体 #1：0粉怎么开始"
"新手做自媒体 #2：第一个视频怎么拍"
"新手做自媒体 #3：涨粉100的真实经历"
```

### Theme Series
```
"涨粉日记 Day 1：从0开始"
"涨粉日记 Day 7：第一个100粉"
"涨粉日记 Day 30：复盘与反思"
```

### Question Series
```
"为什么你的视频没人看？"
"为什么别人的视频能爆？"
"你应该发什么内容？"
```
