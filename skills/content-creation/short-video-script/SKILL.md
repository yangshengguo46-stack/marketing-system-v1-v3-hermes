# Short Video Script Writing

## When to Use
- Writing a 60-90 second video script
- Adapting long-form content into short-form
- Creating a series of related short videos
- Optimizing scripts for platform algorithms

## Hook Formulas (First 3 Seconds)

The first 3 seconds determine whether the algorithm pushes your video. Choose a hook type:

| Hook Type | Pattern | Example | Best For |
|-----------|---------|---------|----------|
| Contrarian | "大家都以为X，其实Y" | "大家都以为早起能成功，其实睡懒觉的人更高效" | 知识科普 |
| Question | "你知道吗？X%的人Y" | "你知道吗？90%的人都刷错了牙" | 生活技巧 |
| Result-first | "用这个方法，我X天Y" | "用这个方法，我7天涨了10万粉" | 教程/经验 |
| Story tease | "那天发生了一件事，改变了我" | "三年前的一个决定，让我少走了五年弯路" | 情感/故事 |
| Visual shock | [画面先于声音] 直接展示惊人画面 | 直接展示前后对比图 | 产品/美妆 |
| Pain point | "你是不是也X？" | "你是不是也每天加班到很晚，却还是做不完？" | 职场/效率 |
| List tease | "X个Y，最后一个最关键" | "3个涨粉技巧，最后一个99%的人不知道" | 干货合集 |
| Authority | "做了X年Y，我总结出Z" | "做了10年营销，我总结出3条铁律" | 专业内容 |

## Script Structure (60-90 seconds)

### 7-Beat Compressed Structure

```
Beat 1 (0-3s):   HOOK — 抓住注意力
Beat 2 (3-10s):  PROBLEM — 痛点共鸣
Beat 3 (10-20s): CATALYST — 引入解决方案/转折
Beat 4 (20-40s): TRY — 展示过程/干货
Beat 5 (40-50s): RESULT — 结果展示/证明
Beat 6 (50-55s): EPIPHANY — 额外洞察/反转
Beat 7 (55-60s): CTA — 引导关注/互动
```

## Pacing Rules

### Energy Curve
```
高 ████      ██████      ████
   ████      ██████      ████
中 ████  ████      ████████      ████
   ████  ████      ████████      ████
低 ████████      ████      ██████
   0s    10s     25s    40s    55s   60s
   Hook  Problem Action Result Twist CTA
```

- **0-3s**: Peak energy (hook)
- **3-10s**: Dip slightly (context)
- **10-40s**: Building (main content)
- **40-50s**: Peak again (result reveal)
- **50-55s**: Brief dip (insight moment)
- **55-60s**: Final peak (CTA)

### Cut Frequency
| Section | Cut Every | Reason |
|---------|-----------|--------|
| Hook (0-3s) | 1-1.5s | Maximum retention |
| Main content (3-45s) | 3-5s | Sustained attention |
| Result (40-50s) | 2-3s | Excitement building |
| CTA (55-60s) | 3-5s | Slower, deliberate |

## Platform-Specific Optimization

### Douyin (抖音)
- **Optimal length**: 60-90s (algorithm favors completion rate)
- **Hook**: Must be visual + verbal (sound-on environment)
- **Text**: Large, high-contrast subtitles (many watch without sound in public)
- **CTA**: "关注" > "点赞" > "评论" — in that order
- **Tags**: 3-5 hashtags, mix of broad + niche
- **Cover**: First frame or custom — must work as thumbnail

### Xiaohongshu (小红书)
- **Optimal length**: 3-5 min (audience expects depth) or image+text
- **Hook**: Aesthetic first — visual quality matters more than energy
- **Text**: Smaller, elegant typography
- **CTA**: "收藏" > "关注" > "点赞" — save rate is king
- **Tags**: 8-10 hashtags, very specific long-tail
- **Cover**: Must be beautiful even as a static image

### Bilibili (B站)
- **Optimal length**: 5-15 min (audience tolerates depth)
- **Hook**: Can be slower — audience chose to click
- **Text**: Standard subtitle style
- **CTA**: "一键三连" (like + coin + favorite)
- **Tags**: Topic tags + custom tags
- **Cover**: Information-rich, can include text overlay

## Series Strategy

### Content Pillar → Episode Breakdown

```
Pillar: "新手做自媒体"
├── Ep 1: 0粉怎么开始？(hook: 痛点)
├── Ep 2: 第一个视频怎么拍？(hook: 教程)
├── Ep 3: 涨粉100的真实经历 (hook: 故事)
├── Ep 4: 这些错误千万别犯 (hook: 避坑)
├── Ep 5: 变现从0到1 (hook: 结果)
```

### Cross-Referencing
- Ep 1 mentions "下一期讲拍摄技巧"
- Ep 3 references "上次说的方法，我用在了..."
- Ep 5 callbacks to Ep 1's pain point

## Quality Checklist

- [ ] Hook within first 3 seconds
- [ ] Clear single topic (one video = one point)
- [ ] Pacing varies (not monotone)
- [ ] At least one visual change every 5 seconds
- [ ] Subtitles are readable and accurate
- [ ] CTA is specific and actionable
- [ ] Title works as a standalone curiosity trigger
- [ ] Cover frame is visually compelling
- [ ] No dead air (silence without purpose)
- [ ] Ending is clean (no awkward cutoff)
