# Content Analysis

## When to Use
- Analyzing a competitor's viral video
- Auditing your own content performance
- Extracting reusable frameworks from successful content
- Understanding why a piece of content worked (or didn't)
- Building a content knowledge base

## Analysis Framework

### Layer 1: Surface Analysis

```markdown
## Content Metadata
- Platform: [Douyin/Xiaohongshu/Bilibili/...]
- Format: [Video/Image+text/Article]
- Length: [X seconds / X 字]
- Published: [Date]
- Author: [Name]
- Category: [知识/搞笑/美妆/...]

## Performance Metrics
- Views: [X]
- Likes: [X]
- Comments: [X]
- Shares: [X]
- Saves: [X]
- Completion rate: [X%] (if available)
```

### Layer 2: Structural Analysis

#### Hook Analysis
- **Hook type**: [Contrarian/Question/Result-first/Story/Pain point/List/Authority]
- **Hook duration**: [X seconds]
- **First line**: "[Exact text]"
- **Visual hook**: [What's on screen in first 3s]
- **Curiosity gap**: What question does the hook create?

#### Beat Breakdown
Map the content to beats:

```
Beat 1 (0-Xs):   [Type] — [What happens] — [Emotion]
Beat 2 (X-Ys):   [Type] — [What happens] — [Emotion]
...
```

#### Pacing Analysis
- Average shot length: [X seconds]
- Cut frequency: [Every X seconds]
- Energy pattern: [Building/Peaked/Valleyed/Steady]
- Dead air moments: [Timestamps with low energy]

### Layer 3: Emotional Analysis

#### Emotional Journey Map
```
Time:    0s    10s    20s    30s    40s    50s    60s
Emotion: 猜测  → 痛点  → 希望  → 紧张  → 满足  → 惊喜  → 行动
Energy:  高     中     中     高     高     中     高
```

#### Empathy Triggers
- **Recognition**: "我也是这样！" — relatable pain points
- **Fascination**: "怎么做到的？" — surprising skill/result
- **Vicarious desire**: "我也想要！" — aspirational outcome
- **Fear**: "我可不想这样" — loss aversion

### Layer 4: Content Quality Audit

#### Strengths
- [What makes this content work?]
- [Which specific techniques are effective?]
- [What emotional beats land well?]

#### Weaknesses
- [Where does energy drop?]
- [Which beats feel rushed or padded?]
- [What's missing that the audience expects?]

#### Improvement Opportunities
- [Alternative hook that could work better]
- [Pacing adjustment suggestions]
- [Additional value that could be added]

## Content Repurposing Extraction

When analyzing successful content, extract reusable components:

### Extractable Components
1. **Hook formulas** — patterns that grab attention
2. **Transition phrases** — smooth segues between beats
3. **CTA patterns** — effective call-to-action styles
4. **Visual motifs** — recurring visual elements
5. **Pacing templates** — energy curves that work
6. **Topic angles** — unique perspectives on common subjects

### Component Library Format
```markdown
## Component: [Name]
- Source: [Which content it was extracted from]
- Type: [Hook/Transition/CTA/Visual/Pacing/Angle]
- Pattern: [The reusable formula]
- Example 1: [Original usage]
- Example 2: [Our adaptation]
- Applicable to: [Which content types]
```
