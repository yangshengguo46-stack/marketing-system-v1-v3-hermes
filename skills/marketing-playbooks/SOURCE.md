# Marketing Playbooks Source

This directory preserves the exact `marketing-skills` snapshot supplied to the
project before product-specific migration work began.

- Original project: `coreyhaines31/marketingskills`
- Installed bundle: `marketing-skills`
- Preserved installed version: `0.1.2`
- Preserved module count: 23
- License: MIT

The snapshot is intentionally not rewritten to match Marketing OS domain
contracts. Product-specific stateful actions belong to native Hermes tools;
these files remain operating playbooks and reference material.

Upstream currently evolves independently. Updating this snapshot must be an
explicit reviewed change, because upstream module names, scope, and required
context can change.
