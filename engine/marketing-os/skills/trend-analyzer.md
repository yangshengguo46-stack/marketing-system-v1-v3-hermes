# trend-analyzer

## 目标
对抓取到的多平台热点数据进行去重、分类、关键词提取、热度排序。

## 前置条件
- 已通过 `hot-topic-scraper` 获取到热点数据
- 传入参数: `hot_data` (aggregate_all_trending 的输出)

## 执行流程

### 第一步：标准化
将各平台不同格式的数据统一为：
```json
{
  "title": "标题",
  "heat_value": "热度指标",
  "source_platform": "douyin/weibo/bilibili",
  "source_rank": "在该平台的排名",
  "url": "链接"
}
```

### 第二步：去重
- 基于标题相似度去重（相同事件在不同平台的重复报道）
- 算法: 提取标题前5个字符为去重key，相同的合并

### 第三步：分类
按内容类型打标签：
- 科技/AI、娱乐/影视、财经/商业、社会/民生、游戏/电竞、体育/赛事、生活方式、其他

### 第四步：跨平台热度排序
综合各平台排名，给出跨平台热度分：
- 抖音排名权重 0.4
- 微博排名权重 0.35
- B站排名权重 0.25

## 输出格式
```json
{
  "categories": {
    "科技/AI": [...],
    "娱乐/影视": [...]
  },
  "top_trends": [...],  // TOP20 跨平台综合
  "cross_platform_hot": [...]  // 多平台同时上榜的热点
}
```
